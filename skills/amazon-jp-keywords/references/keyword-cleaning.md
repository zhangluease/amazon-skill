# 官网词相关性筛选

本环节在采集后、关键词主表交付前执行，只筛选「官网原词」和「官网组合」。完整采集结果留在来源明细，主表使用筛选后的官网词。Amazon 搜索框联想（关联词）不洗词，易逊 ASIN 反查和 ABA 全站搜索词沿用原有保留规则。

## 先确定目标商品

从用户资料、目标 ASIN 商品页、准确型号的官方产品页或适配表，记录目标的品类、整机／配件／耗材身份、品牌、完整型号及版本；查配件时还要明确部件号、部件名和已确认的适配范围。证据位置保留 URL 与页面章节、表格或 PDF 页码。以词找词未提供 ASIN 时，以用户种子词或已识别部件为目标。

仅有同品牌或相近型号页面时，可以参考通用品类名称，但不能把该页的专属规格、功能、附件或适配关系移植给目标。`S8+`、`S8 Pro Ultra`、`S8 Max Ultra` 等写法须作为不同型号核对。目标信息不足时，无法判定的官网词标为「待核实」，继续交付其他来源，报告写明缺少哪项依据。

## 逐词判断

同时检查商品关联与搜索意图，不按关键词长度、来源权威性或一个固定禁词表机械筛选。

| 情况 | 官网词处理 |
| --- | --- |
| 与目标整机／配件／耗材身份一致的准确品名、完整型号、部件号或通用品类词；配件任务中已确认的官方部件名 | 保留，附目标关联证据。品类词可比完整商品名更宽泛，无需强制加品牌或型号。 |
| 属性或用途词与商品主体组成自然的购买查询，且目标确实具有该属性或用途 | 保留；缺少目标规格依据则待核实。只有网页上出现过或看起来像搜索词，不足以保留。 |
| 单独的动作、泛功能、技术或营销描述，缺少明确商品购买对象 | 剔除，例如整机任务里的裸词「給水」「自動乾燥」。 |
| 目标为整机，词表达单独购买某个零部件、耗材或基站 | 剔除。整机包含这个部件，不等于该部件词对应整机购买意图。 |
| 目标为配件或耗材，部件名及型号与目标部件有明确官方对应关系 | 保留官方部件名、部件号及已确认的「适配型号＋部件名」组合；不能只因它是零部件词而剔除。 |
| 不同型号、不同配件、站内推荐商品、导航或图片替代文字带入的无关内容 | 明确不对应目标则剔除；只有关系线索而无确认依据则待核实。停售或停产本身不是剔除理由。 |
| 只在低相关词前添加品牌、型号，或将同页所有词做笛卡尔组合 | 仍按原意图判断；拼接不能使词自动合格，也不证明功能或适配关系。 |
| 用户提供的必保词或禁用词 | 必保词以「用户指定保留」单列依据，未命中时标明查询未命中；禁用词从仅官网来源的主表候选剔除。不得伪造官网证据。 |

可以从已经确认的品名、属性和适配关系生成自然的官网组合词，但要作为新候选单独记录组成依据，再做同样的筛选；不能覆盖原词，不能把组合标为 Amazon 实测联想或买家搜索词。单渠道官网词只要满足相关性与意图要求即可保留，不要求另有 Amazon 或 ABA 命中，也不从缺少热度指标推断没有需求。

## 来源合并与去留

按主流程的归一及去重规则汇总全部来源，再决定主表去留，避免先按官网结论删除同词的 Amazon 记录。

- **有 Amazon 联想来源**：整条关键词保留，不参与本次洗词。包括宽泛词、其他型号、耗材、`純正`、`互換品`、版本不同及关系待核实的词，事实备注照常填写。保持原始联想词与逐种子词的位置记录，不能先套官网规则过滤联想文件或种子词已返回的结果。
- **有易逊或 ABA 来源**：按原有规则保留，不因官网洗词失败而丢失该来源的词或指标。
- **仅官网来源**：「保留」和「用户指定保留」进入主表；「剔除」与「待核实」仅留官网明细。官网同词有多条证据时，综合核对后给出一个结论；存在未解决的适配或版本冲突时标为待核实。
- **官网结论不通过，但有其他来源保留**：主表仍记录全部原始来源，注明「因 Amazon 联想／易逊／ABA 来源保留；官网关联未通过或待核实」，不能把保留解释为官网已证实目标规格或适配。

本次官网词筛选不改变其他渠道的采集、指标口径及去重规则。

## 保存与交付

- `official-keywords.xlsx` 保存全部官网原词与组合词，增加「洗词结论」「洗词原因」「目标关联证据」字段。结论使用「保留」「剔除」「待核实」「用户指定保留」；原因写到具体问题，例如「目标为整机，该词为独立刷头购买意图」或「证据页为 S8 Pro Ultra，未证明目标 S8+ 的此项功能」，避免只写「低相关」。保留原文、官网 URL、证据位置及组合依据。
- `seed-keywords.xlsx` 保存全部 Amazon 联想、ABA 候选和通过筛选的官网候选，增加「保留依据」，区分「Amazon 联想保留（不洗词）」「ABA 保留（不洗词）」「官网洗词保留」与「用户指定保留」。同词的多个依据均记录，原有事实备注和来源明细位置保留。ASIN 任务另行引入官网词时，`keywords.xlsx` 同样按来源分流，易逊与 ABA 候选不洗词。
- 报告按去重后的官网关键词数统计洗前总数、保留数、剔除数、待核实数及用户指定保留数，四种结论之和等于洗前总数。另列因其他来源仍留在主表的未通过官网词数量，避免把官网剔除数直接当作主表减少行数。摘要只展示主表词，链接完整官网明细供复核。

## 整机查询示例

以下用于说明处理边界，不是所有品类的禁词表，也不替代实际 ASIN 与官网核对。

| 候选及来源 | 假设目标为 S8+ 扫地机器人整机时的处理 |
| --- | --- |
| 「水拭き」「モップ洗浄」「自動乾燥」「給水」「ゴミ収集」，仅官网来源 | 裸功能或动作描述，剔除，不直接作为整机关键词。 |
| 「デュアルラバーブラシ」「メインブラシ」「モップ」「4way全自動ドック」，仅官网来源 | 部件、耗材或基站购买意图，剔除；如果目标改为对应配件，则按官方部件和适配依据重新判断。 |
| 「S8 Pro Ultra メインブラシ」，仅官网组合 | 加型号后仍是刷头购买意图，剔除。 |
| 「S8 Pro Ultra 水拭き」，仅官网组合，证据只覆盖 S8 Pro Ultra | 不能证明与目标 S8+ 关联，不因带型号而保留。 |
| 「ロボット掃除機」，仅官网来源，已确认目标为扫地机器人 | 通用品类词，保留。 |
| 「Roborock S8+」，仅官网来源，支持页已明确目标型号 | 准确目标型号，保留。 |
| 「ロボロック S8 Max Ultra 消耗品 正規品 メインブラシ」，来自 Amazon 联想 | 保留、不洗词，备注型号差异及适配未确认。 |
| 「給水」，同时来自官网和 Amazon 联想 | 关键词仍保留；官网项记剔除，保留依据记 Amazon 联想，不将官网的剔除结论应用到整行。 |

交付前核对：全部 Amazon 联想原词都有主表映射，原始明细及位置完整；官网明细没有因洗词少行；仅官网来源的剔除及待核实项未进入主表；官网计数与主表去留能按来源解释。
