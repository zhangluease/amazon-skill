# 新版日本站 Listing：写作与核对

先确认卖的是什么，再安排关键词。原始关键词、品牌和型号保留日本市场实际写法；中文译义只供理解。准确区分整机、兼容配件、耗材和套装，给定词表中的语义明确的对象适配关系直接采用；原装属性等输入未表达的信息不补造。

本技能只面向新版标题与独立小标题结构，不生成旧版长标题。不要将浏览器标签、搜索摘要或图片 alt 中以 `|` 合并的文字当成一个商品标题；分别读取页面主标题和其下的灰字。

## 字段分工

| 字段 | 上限／形式 | 优先内容 |
| --- | --- | --- |
| title | ≤75 字符 | 已确认品牌 → 适用的主要购买识别编号 → 完整商品名 → 用途或适配关系 |
| item_highlight | ≤125 字符 | 先为已知包装信息预留字数，按本品选购条件补充代表型号、规格或用途，末尾集中写包装信息 |
| bullets | 固定 5 条，每条全文 ≤250 字符 | 「相关词／短主题：具体说明」，正文承接对应购买问题；完整适配清单可分多条 |

字符包含空格和标点，全半角均按一个字符计。五点按全文计数，包含短主题、适配型号及分隔符，每条最多 250 字符，合计最多 1250 字符。JP 后台词预算为 499 UTF-8 字节。实际类目与后端限制仍需满足。数字配置见 [quality_policy.json](../knowledge/quality_policy.json)。

## 标题与小标题

- 以已确认的本品品牌开头。品番是购买识别条件时，将已确认的主要目标品番紧跟品牌，或在没有品牌时置首，然后写完整日文商品名。尽量在前 35–40 字符呈现这些信息，优先保留完整写法。未确认品牌和购买时不使用的编号可省略。
- 标题后段写本品实际用途或适配关系。替换品可补充有识别价值的其他品番。确认是兼容替换件时可用「互換品」等准确关系词收尾。按规格适配时使用有据的适配条件，独立商品写真实用途或选购特征。适配对象型号优先放小标题及五点。
- 超长时先删主观修饰、重复品名、次要功能和次要型号；保留完整品名、关键编号、关系和必要版本，不截断编号。普通材质尺寸仍留五点；只有无法拆离商品身份或用户／类目明确要求时，在 field_strategy.exceptions 记录保留理由。
- 小标题先为已提供的实售数量和套装组成预留字数，再按选购条件补充代表型号、规格或用途。将包装信息集中在末尾一处，按实际计数单位表达。多组件在同一尾段分别列明。已确认的使用特征可放在包装信息前。
- 型号适配型耗材从本品确认清单中选 3 个不同的代表机型，并引用对应适配事实。优先依据可用指标，指标缺失时按购买代表性排序。少于 3 个按实写，125 字符内优先保留完整的实售包装信息，必要时减少机型数并记录原因。五点列全名单，按规格选购或独立使用的商品补充实际选购条件或用途。
- 主耗材、随附配件及套数分别计算，单位按实际使用枚／個／本／袋／巻／組。资料缺哪项就记录哪项，写入已确认的数量和组成。

## 五点的默认组织

| 主题 | 回答买家什么 | 可写内容与边界 |
| --- | --- | --- |
| 1. 商品与实售内容 | 买到什么、包含什么 | 完整商品名、实际组成、有识别价值的编号与数量。必要时说明资料明确的不含物 |
| 2. 性能与使用价值 | 有什么作用、为什么选它 | 已确认的结构／规格／测试结果如何支持用途或价值；仅有用途资料就写用途，不把设备性能、竞品效果或材质直接变成本品性能承诺 |
| 3. 选购条件 | 该如何选，买了是否适用 | 型号适配写完整名单、后缀与限制。规格型写配合条件，独立商品写影响选择的本品规格或适用场景 |
| 4. 使用与维护 | 如何安装、使用、维护或更换 | 按实际商品选择。周期、寿命及更换迹象使用本品资料，需定期更换时才设更换主题 |
| 5. 品质与购买事项 | 还有什么需要确认 | 前四点未覆盖的真实规格、检验事实、包装保护或安装确认事项；不以泛泛品质保证、原装同等或未经说明的售后承诺凑第五点 |

这些主题供选用和排序，按本品购买决策组织，可用实际规格、操作或使用限制替换不适用的主题。长适配清单先按每条全文 250 字符分组，通常占 2–3 条。位置不足时优先合并或省略独立性能点，在 exceptions 记录取舍。保留所有已确认型号及完整后缀。五条仍无法同时满足长度和完整性时，保留完整草稿并标为超限。缺性能、周期或检测依据时使用其他已确认购买信息并标明缺口，不虚构五种主题；一次性及通用耗材不套用更换／清洗模板。

每条开头将相关可用词融入短主题或首句，采用「短主题：具体说明」（全角或半角冒号）；旧稿的【主题】正文仍可读取。不为开头流量词写不自然语序，不把「确认」「安心」等空标签当作卖点。

已有竞品分析和评论只用于选购买问题、识别混淆或关注点；本品资料与可信原词决定可写事实。不把重新开展竞品调研设为写作前置条件。售后政策按允许字段另行处理；五点默认用客观品质和购买信息建立信任，不写退款／无条件保证、联系方式、价格或促销内容。

## 收稿检查

对照 05.field_strategy 与实际文案复核：

1. **分工与关键词**：标题开头核对已确认品牌、适用的目标品番及完整商品名。按型号选购时核对已确认代表机型，已知实售包装信息集中在小标题末尾，五点主题有具体购买价值；必要编号可重复，不整句复制或机械塞词。
2. **本品一致**：品牌、本品编号、适配对象、数量与规格在标题、小标题和五点一致，代表型号在完整名单内且互不重复，主品和配件数量分列，装数表达集中于小标题末尾。
3. **依据与表达强度**：性能、收益、更换迹象、周期及品质声明逐项有依据；不把竞品评论、设备效果或售后推测写成本品事实。给定关键词继续默认可信，不要求二次核验。
4. **完整性与日语**：按原清单核对全部型号及后缀、引用与范围；读起来是自然的短主题和具体说明。材质尺寸在合适正文，不遗漏。
5. **可交付状态**：核对标题、小标题及每条五点的全文字符数，替换／删除模板占位符、教学说明、未确认承诺及装饰符号。资料缺口写入内部记录，不把草稿痕迹留在上架文案。

句式示例见[按选购条件写作示例](../knowledge/style_snippets.md)，示例与参考页面不充当本品事实。
