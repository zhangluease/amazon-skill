# 日本亚马逊知识产权初筛

只判断日本销售情景，默认中文回答、日语检索。技术类权利包含特許和実用新案（实用新型）。商标排除在初筛范围外。执行时读 [J-PlatPat 接口用法](references/jplatpat-api.md)，比较与补查按需读[日本检索指南](references/japan-search.md)，交付时读[报告模板](references/report-template.md)。

**J-PlatPat 检索、公报读取、案号链接和状态核对均通过终端运行 Python 脚本。** 需要用网页补查缺项时，须经用户明确同意。

## 1. 确认要销售的商品

从用户资料或页面提取：商品名称与用途、主体外形与结构、包装、计划使用的图片和文案，以及销售方式（自有品牌、通用商品、经销或兼容配件）。

- 接受 Amazon.co.jp 链接、ASIN（按日本站解析）或用户直接提供的资料。其他站点页面可作产品资料，但先确认目标市场为日本，不扩展到其他国家。
- 竞品是检索线索，不能将竞品的图片、结构或授权自动当作用户拟售商品的事实。
- 实际查看可读取的商品图片，至少了解主体和可见结构；区分页面明确说明、用户陈述、视觉推断和未知事实。没有内部资料时不臆测技术结构。
- 页面无法访问时使用已有材料继续可做的部分。若无法识别商品，则一次说明最少需要的名称/用途和图片或页面内容，等待这些必要资料后再开始商品比对。

在开始检索时简要列明本轮商品、JP 范围和重要缺口，不强制增加用户确认步骤。

## 2. 建立日本检索词

根据实际商品生成：日语常用品名与同义词、关键形状/结构/功能，以及已知厂商、竞品或权利号。英语、罗马字可补充，不能替代日语。

保留词语与产品事实的对应关系。分类代码从官方分类工具或可靠候选记录获取，不能猜造。不要仅复制亚马逊长标题，也不要只用“日用品”等过宽词语；具体查询方式见检索指南。

## 3. 按日本来源实际检索

| 范围 | 必做检查 |
| --- | --- |
| 外观（意匠） | 日语物品名与适用分类；候选附图、整体/部分意匠、相关意匠 |
| 发明（特許） | 日语产品及技术用语；日本申请/授权、现行权利要求与产品结构 |
| 实用新型（実用新案） | 同次技术检索中的实用新案；登记状态、权利要求与产品结构 |
| 著作权（著作権） | 图片、图案、角色、包装和文案的原始来源及授权范围 |
| 不正竞争 | 对近似复制、知名标识或包装线索，补查日本商品形态模仿与周知/著名表示问题 |

从当前技能目录定位 [`scripts/jplatpat.py`](scripts/jplatpat.py)，执行所需的 `search patent` 或 `search design`，读取 `result.json` 后筛选候选。取文献用 `patent-claims` 或 `design-pdf`，核对状态按下一节选择 `case-status` 的用法。用户已给出脚本支持的准确编号时，可直接执行对应命令。复用本轮已取得的响应及 `case_url`。商品事实和素材来源可以另查品牌官网、竞品页面或原始发布页。

脚本缺失、接口受阻或缺少分类、文献、当前状态等信息时，记录具体原因和待补事项，继续用现有证据完成可做的部分。区分查询失败与成功零命中。获准网页复核后，按具体候选编号和缺项查看对应页面。

逐条浏览脚本保留的候选题名和书目，相关案件再读公报和权利要求。每条查询记录日期、来源、查询词、命中数、接口返回数、保留数、特許和実用新案候选数及实际审阅数。超过 500 条时先审阅脚本保留的前 500 条，再按商品事实补查剩余范围。披露日期缩小、截断、未读及无法分类的记录，保存原始响应和 `result.json`。

## 4. 核对相关候选

按准确日本申请号/登记号与权利类型去重，记录权利人、证据引用、状态核对日期、保护内容、与本品的关系及未明事项。接口证据直接引用保存的 `result.json`、`claims.txt` 或 `gazette.pdf`。有 `case_url` 时可一并附上。状态查询缺少明确阶段时，标注“未核实”。国际注册或专利同族须核实在日本的效力，不能仅凭境外记录认定日本受保护。

按准确申请号和权利类型运行 `case-status`。对影响评级的特許和実用新案加 `--history`，获取案件状态和公开登记、缴费、审判资料。实用新案可引用明确的登记消灭日。上架前行动列剩余缺项。

- **意匠**：比较公报必要视图与本品，关注保护部分和整体视觉特征；仅改颜色、Logo 或小附件不直接视为排除。视图不足时写明不能判断的部位。
- **特許和実用新案**：按准确公开号、授权号或登记号读取日文权利要求，对相关独立权利要求逐项列出“必要要素—本品证据—对应/不对应/未知”。仅有查询列表状态码或公报时，当前权利状态填“未核实”。看不到的内部结构记未知。
- **著作权/不正竞争**：核查可保护表达、来源、授权或模仿依据。供应商提供、网上可下载、他人也在卖、无注册号，均不是排除理由。

疑似失效要核实具体日期与记录，申请中与已授权分开；尚未授权的申请单列未来风险。对明显不相关的候选简记排除理由，关键候选保留证据。不把登记库无结果当作穷尽所有权利。

## 5. 评级并交付

每个范围分别给出检索状态（完成/部分完成/未执行/不适用）、风险和置信度（高/中/低），附具体证据。这里的“完成”仅指本轮声明的查询与候选核对完成，不代表穷尽检索；“不适用”须有本品事实依据。

| 风险 | 使用条件 |
| --- | --- |
| 高 | 已有具体日本权利或原始作品证据，且本品存在明显对应/使用问题，需要优先处理 |
| 中 | 有具体相近、使用或授权疑点，现有证据支持关注，但尚不能充分确认或排除 |
| 低 | 本轮必要检索及相关候选核对已有依据，未发现明显冲突；写明有限范围 |
| 待定 | 未检索、来源受阻，或缺少状态、必要视图、权利要求、产品事实等，不能支持评级 |

置信度说明已给判断的证据强度，不能用“低风险、低置信度”替代待定；待定项的置信度写“—”。风险是运营初筛意见，不能表述为已裁定侵权。

同时展示“已查明最高风险”和本轮范围内的“待定/未完成事项”。范围内存在关键待定项时，不给整体低风险结论；已知高风险仍须醒目标出。上架前建议围绕具体疑点列出补证、改图、改文案、重新设计或交日本弁理士/律师核查等动作。

按报告模板生成一份 Markdown。默认保存至工作区 `reports/<日期>-<商品简称>/report.md`，必要截图、公报摘录或授权材料保存在同目录 `evidence/`，证据用相对链接；无文件能力时在对话中完整交付。保存材料须对应实际查看来源，未经允许不把用户未公开图片上传到外部搜图服务。

交付前核对：所有链接与案号可追溯、日语查询实际执行情况如实记录、比较结论有产品证据、所有未完成范围已披露。结尾简短注明：本结果是日本站知识产权初筛，不构成法律意见或上架保证。
