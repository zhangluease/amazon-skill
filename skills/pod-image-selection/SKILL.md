# POD 选图

原名 `pod-huaban-materials`。花瓣是参考素材来源之一。默认先让用户选择有市场数据的竞品图片，再根据用户选定的视觉方向找类似素材。

## 工作流程

1. 复用浏览器中卖家精灵插件的登录授权，通过脚本按关键词查询美国站商品及父体销量、主图。
2. 按父体近 30 天销量降序展示前 30 张主图，等待用户多选。
3. 实际查看选中的图片，提取图案元素、风格、配色、构图，去花瓣检索类似素材。

用户唯一必填输入是**关键词**，例如 `pet house`。站点固定为**美国站 Amazon.com**，不要求用户再指定国家、ASIN、图片风格或自检命令；风格在用户选图后提取。搜索与 ASIN 清单构建由 skill 内部自动执行。

用户明确只要直接找素材、提供参考图或要求跳过竞品时，直接进入第三阶段，不强迫走完整流程。

## 第一阶段：取得并排序竞品

先读 [卖家精灵浏览器授权与取数](references/sellersprite-access.md)。默认使用固定 Playwright 脚本正常操作插件界面、读取商品表格，不使用 Agent 逐步截图点击的 Browser Use 流程。

默认候选范围为**卖家精灵按关键词查询到的美国站商品**。用户已确认统一从卖家精灵取数据，替代早期“Amazon 插件已加载结果内排序”的方案。记录关键词、匹配方式、站点、销量窗口、查询时间与结果来源，不将产品库查询说成 Amazon 当前实时搜索页。

采用**专用持久浏览器配置 + 原卖家精灵插件**。入口自动检查 Node.js 18+、Python 3.9+、锁定版本 Playwright 与配套 Chromium，并寻找本机 Chrome/Edge 已安装的插件程序；仅缓存插件程序文件，不复制日常浏览器的登录数据。首次打开专用浏览器，由用户正常登录/同步卖家精灵；之后复用同一专用配置，免去 HAR 导出，不要求无痕窗口。目录、缺依赖和桌面处理见 [环境自检](references/environment.md)。

在 skill 目录运行，Agent 将路径换成实际绝对路径，输出目录每次查询单独建立：

```sh
node scripts/sellersprite_browser.cjs search --query 'pet house' --out /absolute/run
```

看到即时事件 `seller_authorization` 的 `awaiting_login` 时，**立即告诉用户在已打开的专用浏览器完成登录或验证，并继续等待同一个进程**；不要等超时或进程结束才通知。默认等待300秒，可用 `--authorization-timeout 600` 延长。登录完成自动继续同一关键词；取消、超时、无交互桌面或再次失效时停止并报告 `authorization.json`、`browser-status.json`，不循环重试。登录态由浏览器/原插件维护，不承诺永久有效。默认有窗口，可选 `--headless`；无头会话需要授权时，仅在可操作桌面切换到可见浏览器。云端无桌面不能凭空弹出本机窗口。

脚本在 Amazon.com 的插件“产品查询”中选择“关键词”，取得本次加载的候选，按**父体近30天销量列**排序取前30。只承诺 `returned_candidates_only`，不声称全量全局前30。界面未显示总匹配数时保留未知；K/万等显示数值标为 `sales_precision=plugin_display`，不冒充接口原始精度。不能拿子体销量、BSR、评论数替代父体销量。宽泛词可能匹配非目标品类，不暗中改词或删除高销量的非目标品类。

默认按 ASIN 去重，并记录策略；同父体下不同 ASIN 的主图仍可供选择，不默认按父体去重，也不相加父体销量。同销量按收集顺序排列。缺销量、缺图或缺响应时明确标记，不能补零或伪造排名。取到不足 30 个有效候选时如实交付。

表格不完整、关键词查询未确认完成、账号拒绝或无法辨认父体销量列时按失败处理，不用旧表格充当新结果。`sellersprite_plugin_client.py normalize` 只规范公开商品数据，不读取 HAR、不联网。仅用户明确要求接口诊断时才读 [手动抓包](references/capture-plugin-requests.md)，不要在普通查询失败后自动要求用户导出 HAR。

验证边界：已验证原插件加载、未登录界面识别，以及自建测试扩展的持久会话复用、失效恢复、取消和超时。原插件真实账号登录后的关键词查询尚待试用确认；不能用历史 HAR 接口成功或模拟测试代替这项验证。

## 第二阶段：主图多选

交付编号 1–30 的主图图集，附 ASIN、父体预估近 30 天销量、商品链接、来源与时间。保留商品主图原貌，不先将图片变成新设计。主图可能含包装、文案、摄影背景；父体总销量不能证明图中具体变体/图案热销。

用 `scripts/render_product_gallery.py 任务目录/ranked-products.json` 生成可多选的本地 `products.html`。用户可回复编号或从页面保存选择 JSON。保存所选编号与 ASIN 的映射为 `selected-products.json`。**必须等待用户选择后再提取元素、搜索类似素材**，不替用户自动选定喜欢的图。

## 第三阶段：提取元素与找参考图

逐张查看已选主图，区分可迁移的图案元素与商品外形、商标、IP 角色、包装、文案和摄影背景。记录主体/动物/植物、装饰元素、绘画技法、配色、布局、文字角色、用户希望保留或排除的部分。分清看见的事实与推断，不凭商品标题生成视觉结论。

按每张选图生成主题词、风格词和组合搜索词，分别记录其来源 ASIN。多选图片风格不同则分组找，不强行融合成一种。暂不清楚应提取哪个区域时才询问用户。

花瓣检索复用 [素材检索与初筛](references/huaban-workflow.md) 及现有 `huaban_browser.cjs`、`huaban_tools.py`。自动处理运行环境与真人验证接管。用户指定其他素材来源时按实际可用渠道扩展，不能宣称尚未实现的来源已经接通。图片必须看图初筛、去重，保留来源及“授权待核实”。

## 产物与限制

在当前项目 `reports/pod-selection/<日期>-<主题>/` 保存请求计划/响应、排序结果 `ranked-products.json`、竞品主图 `products.html`、`selected-products.json`、元素分析 `visual-elements.json`、参考素材 `gallery.html`/`candidates.json` 和中文 `report.md`。只生成本轮实际完成阶段的产物，用户选择前不生成伪造的选图或分析结果。

接口失败、授权失效、登录/验证码和真实无数据分别报告。未取得实际可查看图片时不宣称图集已完成。销量和主图用于市场参考，不能证明设计因果或商用授权；竞品图、花瓣采集和会员素材均不自动具有 POD 商品印刷授权。
