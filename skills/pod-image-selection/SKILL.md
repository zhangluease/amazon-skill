# POD选图

输入关键词，例如 `pet house`。固定美国站，默认Amazon搜索第一页，配送目的地（Deliver to）默认按国家选择美国，不指定邮编。使用 `--amazon-country JP` 可改为配送到日本；需要具体美国地区时另加 `--amazon-zip`。配送国家与搜索站点独立，选择日本仍搜索Amazon.com。所选图片决定后续素材搜索的主题和风格。

## 1. 查询竞品并等待选图

在skill目录运行，脚本和输出路径按实际位置填写：

```sh
node scripts/sellersprite_browser.cjs search --query 'pet house' --out /absolute/run
```

入口自动处理环境与会话，按“Amazon匿名HTTP搜索ASIN→卖家精灵批量查销量/主图”执行，按父体近30天销量降序展示全部有效候选。

展示 `products.html`，用户可回复编号或导出选择JSON。将选中编号与ASIN保存为 `selected-products.json`，**等待用户选择后再继续**。

分页、候选范围与错误处理见 [竞品查询](references/sellersprite-access.md)；授权或环境问题见 [环境与人工接管](references/environment.md)。

## 2. 在花瓣以图搜图并筛选

按已选ASIN从排序数据取对应主图，逐张原样提交花瓣“以图搜索”。每张检索完成后随机冷却4–6秒，再提交下一张；入口在连续命令间共享频控并串行执行图片搜索。记录参考图、来源ASIN、图片摘要和实际结果页；多选时分别检索，再合并去重。具体命令及花瓣会话要求见 [花瓣检索与初筛](references/huaban-workflow.md)。

实际看图后，按主体、绘画风格、配色、构图和装饰元素筛选，区分图案与商品外形、商标、文字、包装及摄影背景。可从合适结果继续扩展相似图和推荐画板，保留来源、筛选理由和授权状态。用户明确要求关键词补搜时才提取搜索词；默认流程无需先生成 `visual-elements.json`。

用户直接提供参考图或明确只找素材时，从本阶段开始。

## 3. 适配产品并制作效果预览

用户要求选图后制作时，进入 [PODQHY 制作流程](references/podqhy-workflow.md)。用户未选素材时承接上一阶段的选图；用户明确让你自行找图测试时，自己选择合适图片并完整执行，不再让用户挑图。

**处理产品尺寸前先明确目标产品。** 当前任务已提供 PODQHY 产品编号/SKU、商品链接或已明确选定产品时直接沿用；未指定时主动询问“请提供 PODQHY 商品链接或产品编号/SKU，以及最终图片的宽:高比例（如 1:1、4:5、16:9）”，等待产品信息后再读取模板、适配尺寸和上传。比例只作为末尾处理参数记录，不在输入环节新增确认；已有的信息不重复询问。仅在颜色、规格会影响设计模板且尚不明确时一并询问。用户明确授权自行选产品时可以自行选择并记录；自行找素材的授权不包含自行选产品。P16900 仅为验证案例，不是默认 SKU。具体选择与记录规则见 [产品选择](references/podqhy-workflow.md#产品选择)。

复用已登录的可见浏览器；需要登录时弹出页面交给用户。优先用请求 API 获取产品模板和原图，从实际模板逐面读取尺寸，不能把示例产品的 2000 × 2000 写成固定规格。用 Pillow 依次完成尺寸适配、空白比例和透明度检测、必要的透明底处理。满印判定是像素启发式，需结合实际图案复核。

将处理后的素材放入所有设计面，检查铺满尺寸，并按实际效果视角列表逐张导出，**列表中每一张效果图都要交付，不能只选正背面或几个代表视角**。成品图只包含已渲染的产品效果，不包含右侧缩略图栏、放大按钮、工具栏等页面控件；优先导出原始画布，受限时只截取实际画布区域。用 [全部效果图导出](references/podqhy-workflow.md#全部效果图导出) 的脚本校验数量与缺失视角，并生成逐张图片和 `effects.html` 完整图库。素材对比图与操作截图另存，不计入效果图数量。

**全部效果图导出后，最后统一处理出图比例。** 运行 [末尾比例处理](references/podqhy-workflow.md#末尾统一处理出图比例)，将整套效果图按前面记录的宽:高比例生成最终图片及最终图库。比例缺失时只补问这个输入，不默认正方形，也不增加中间确认环节。默认居中补白，保留完整产品；必须修改真实图片像素尺寸，不能只改 HTML 显示比例。所有视角处理齐全后，最终只交付 `final-effects/` 中的图片和图库，过程截图、素材对比通过记录链接查看。

**最终效果必须交给用户确认**，确认前停在预览，不保存设计、不加入购物车、不下单。数据读取、素材下载与图像处理有脚本；当前登录态下的上传和预览可使用站点界面，不能宣称未实测的 API 写入已经成功。

## 交付

结果放在当前项目 `reports/pod-selection/<任务>/`。竞品阶段交付 `products.html` 和排序数据；素材阶段交付 `gallery.html`、`candidates.json`、`report.md`；制作过程保留模板数据、来源记录、逐面 PNG、处理清单和对比图，最终交付 `final-effects/` 中按用户比例处理的全部视角纯效果图、`effects-manifest.json` 和 `effects.html`。交付图片数与实际视角数一致，像素宽高比符合用户输入，缺失时明确说明，不标记整套完成。仅生成本轮已完成阶段的文件。参考素材默认标记“灵感参考，授权待核实”。
